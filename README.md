MediCore API is a robust clinical backend built with Java 17 and Spring Boot 3.
It provides a secure, RESTful infrastructure for managing patients, staff, and medical records.
The system features JPA-based data persistence, JWT authentication, and real-time telemetry.
Engineered for scalability, it supports complex clinical workflows across multiple hospital departments.
This backend serves as the single source of truth for the entire MediCore health ecosystem.

## Technologies
- **Java 17**: Core language for high-performance enterprise logic.
- **Spring Boot 3**: Framework for rapid RESTful API development and security.
- **Spring Data JPA**: Abstraction for SQL data persistence.
- **Spring Security**: Managed authentication and authorization flows.
